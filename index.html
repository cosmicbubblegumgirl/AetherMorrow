Weather planning studio

Aethermorrow

Aethermorrow blends trip planning, forecast context, activity scoring, and fishing recommendations into a polished React and Express project.

Frontend React, Vite, Framer Motion, Recharts, and Lucide icons.
Backend Express API routes for forecasts, activities, fishing spots, and saved plans.
Local Run Install dependencies, then run npm run dev from the repository root.

This GitHub Pages entry point keeps the public project page reachable while the full app remains available from the repository source.
